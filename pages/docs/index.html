Complete guide and changelog for PDF Master Pro

About PDF Master Pro

PDF Master Pro is a complete PDF toolkit that runs entirely in your browser. All processing is done locally on your device, ensuring maximum privacy and security for your documents.

Privacy First

Your files never leave your device. All PDF operations are processed locally using WebAssembly technology, ensuring complete privacy and offline functionality.

Getting Started

PDF Master Pro is easy to use. Simply select the tool you need from the dashboard and follow the on-screen instructions.

  • Click on the extension icon to open the popup menu
  • Select a tool from the dashboard or quick tools
  • Drag and drop your files or click to browse
  • Configure options and process your files
  • Download the result

System Requirements

  • Modern web browser (Chrome, Firefox, Edge, Safari)
  • JavaScript enabled
  • Minimum 4GB RAM recommended for large files
  • No internet connection required (except for OCR language packs)

Available Tools

Organize

  • Merge PDF - Combine multiple PDF files into one
  • Split PDF - Split PDF into multiple files
  • Rotate - Rotate PDF pages
  • Organize - Reorder and organize pages
  • Remove Pages - Delete specific pages
  • Extract Pages - Extract specific pages

Convert

  • JPG to PDF - Convert images to PDF
  • PDF to JPG - Convert PDF pages to images
  • Word to PDF - Convert Word documents
  • HTML to PDF - Convert web pages to PDF

Edit

  • Compress - Reduce PDF file size
  • Crop - Crop PDF pages
  • Watermark - Add watermarks
  • Page Numbers - Add page numbers
  • Redact - Redact sensitive information

Security

  • Protect - Password protect PDFs
  • Unlock - Remove password protection
  • Sign - Add digital signatures

Advanced

  • OCR - Extract text from scanned documents
  • Compare - Compare two PDF files
