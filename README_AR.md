## 🚀 الخطوات التالية

### الأسبوع 1-2: مكتبات PDF
```bash
cd mobile-app
npm install pdf-lib
npm install react-native-blob-util
```
ثم تنفيذ العمليات الفعلية في:
- `/mobile-app/src/services/pdf/merge.ts`
- `/mobile-app/src/services/pdf/split.ts`
- `/mobile-app/src/services/pdf/compress.ts`

### الأسبوع 3-4: الشاشات المتبقية
إنشاء 8 شاشات للأدوات المتبقية باستخدام `MergePDFScreen.tsx` كقالب.

firebase login
cd backend
